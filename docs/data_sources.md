**SR Legacy is still actively maintained and recommended by USDA**. The "Legacy" name is a bit misleading here. It's called that because it's the continuation of the old "Standard Reference" database, which they rebranded when they created the new FoodData Central system in 2019.

The USDA actually recommends:
- **Foundation Foods** - Most accurate, lab-analyzed, but only ~800 foods
- **SR Legacy** - Broadest coverage (~8,000 foods), still updated
- Use both together for comprehensive coverage

So SR Legacy isn't deprecated - it's still the go-to for broad whole food coverage. Foundation Foods is more detailed but much smaller.

Think of it this way:
- Foundation Foods = Deep but narrow
- SR Legacy = Wide but slightly less detailed
- Both are actively maintained and appropriate for modern apps

Use Foundation Foods where available (higher quality data), falling back to SR Legacy for everything else.
